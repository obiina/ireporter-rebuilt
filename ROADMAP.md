# Roadmap

This roadmap describes proposed work, not completed work or claimed hours.

## Core rebuild
- [x] Express API structure and MongoDB models
- [x] Registration and login with password hashing
- [x] JWT authentication middleware
- [x] User-owned report operations
- [x] Admin-only report review and status changes
- [x] Request validation and baseline security middleware
- [x] API test suite starter

- [ ] Add integration tests against an isolated MongoDB instance in CI
- [ ] Add accessibility review and a refreshed browser interface
- [ ] Add deployment automation, backups and operational runbooks
- [ ] Conduct an independent security review before any public deployment
