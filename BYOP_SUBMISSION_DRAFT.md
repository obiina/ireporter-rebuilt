**Description (draft):**
iReporter is a civic reporting application concept that enables users to submit and track community concerns, while administrators can review reports and update their status. I originally developed iReporter as a personal demonstration project and have rebuilt its backend with Node.js, Express, MongoDB, secure password hashing, JWT authentication, role-based access controls, request validation and automated tests. It uses fictional demonstration data and is not represented as a live public service.
